# Security policy

Report vulnerabilities privately through GitHub's "Report a vulnerability"
(Security tab) on this repository. Please do not open public issues for
security problems. We aim to reply within five working days.

Scope: the code in this repository. Your own deployment's configuration
(secrets, Cloudflare account, DNS, email domain) is your responsibility; see
[docs/security.md](docs/security.md) for the model and hardening checklist.
