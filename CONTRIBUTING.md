# Contributing

Thank you for helping. Small, focused pull requests are easiest to review.

1. Read [AGENTS.md](AGENTS.md) — the same rules apply to people and agents.
2. `npm install && npm run setup && npm run dev`.
3. Make the change with tests (`tests/`), docs (`docs/`, module README) and seed data if relevant.
4. `npm run check && npm run build` must pass.
5. Describe what you verified (tests, browser, widths) in the pull request.

New modules are welcome when they are generally useful to small businesses
(bookings, purchasing, timesheets, payments). Keep business-specific logic in
your own fork.

By contributing you agree that your contributions are licensed under the MIT licence.
