The business system you own, not rent.

Open-source CRM, stock, quotes and invoices running on Cloudflare Workers.

Get the code Have it set up

MIT licensed. Runs in your own Cloudflare account.

One accepted quote moves four modules.

Modules talk through typed events, so nobody types a record twice.

  1. Quotes

    Your customer opens a private link and accepts the priced offer.

  2. CRM

    The deal moves to won, beside the contact, notes, tasks and website requests. The pipeline is drag and drop.

  3. Invoices

    The invoice takes the next number with no gaps, VAT per rate, bank-transfer details and a public link. Payments and overdue dates are tracked.

  4. Catalog and stock

    Issuing it deducts stock in the ledger. Low stock raises an alert, and every product gets a public page with Product structured data.

Switch any module off in sistemele.config.ts.

Questions before you fork it

What does it cost to run?

The code is free. Small use fits the Cloudflare Workers free tier; above it, Cloudflare bills by usage (see Workers pricing). Email runs on your own Resend account.

How is it different from a SaaS CRM?

You own the code and the data. It runs in your Cloudflare account; export the D1 database or change anything, whenever you like.

Is it production ready?

It ships with tests against a real local D1, roles, an audit log, CSRF protection and server-side totals. Review it like any code you deploy.

How are modules added?

Run npm run module:new or ask your coding agent; AGENTS.md lists what a module needs. Then add its id to sistemele.config.ts.
