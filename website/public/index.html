The wheels are already here.

  • Sign-in and security

    Magic links by email, owner, admin and member roles, an audit log, CSRF checks, security headers and rate limits.

  • CRM

    A leads inbox with owners, follow-up dates and sources; a lead becomes a contact and a deal in one step. Pipeline stages you add, rename and reorder, each with a win probability.

  • Quotes

    Numbered quotes with VAT per rate. The customer accepts or declines from a private link, and the deal moves to won.

  • Invoices

    Gap-free numbers, VAT per rate and partial payments. Issued invoices never change; a void and a new invoice correct them.

  • Catalog and stock

    Products and services, a stock ledger with receipts and counts, low-stock alerts and public product pages.

  • Website and blog

    Markdown pages and posts with drafts, scheduling and RSS. Agents draft; owners and admins publish.

  • Search

    Server-rendered pages with unique titles, canonical URLs, Open Graph, JSON-LD and a sitemap. Previews are never indexed.

  • Dashboard

    Drag-and-drop cards, KPI metrics from every module, four templates and a layout saved per person.

  • MCP endpoint

    Every module’s tools at /mcp. An API token’s role limits what an agent can call.

    The customer opens a private link and accepts the priced offer.

  3. Invoices

    The invoice takes the next number with no gaps, VAT per rate, bank-transfer details and a public link.

  4. Catalog and stock

    Issuing it deducts stock in the ledger, and low stock raises an alert.

Questions before you fork it

Which coding agents can use it?

Any agent that reads the repository: AGENTS.md is plain Markdown. Claude Code also gets the slash commands, and agents that support skills install npx skills add aimantas/sistemele.

Can I switch modules off?

Yes. Remove the module’s id from sistemele.config.ts and its routes, screens, widgets and MCP tools go. Its tables stay.

What does it cost to run?

The code is free under the MIT licence. Small use fits the Cloudflare Workers free tier; above it, Cloudflare bills by usage (see Workers pricing). Email runs on your own Resend account.

Is it production ready?

It ships with tests against a real local D1, roles, an audit log, CSRF protection and server-side totals. Review it like any code you deploy.

Can you set it up for us?

Yes. The maker, an independent developer in Lithuania, sets it up and adapts it to your company. Email hello@sistemele.dev.
